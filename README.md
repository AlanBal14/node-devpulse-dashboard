# DevPulse Live - Realtime Dashboard Node.js 🚀

Dashboard interactivo en tiempo real construido con **Node.js**, **Express**, **Socket.io** y **Chart.js** para la materia de Programación para Internet.

## 🌟 Funcionalidades Principales
- **Comunicación en Tiempo Real (WebSockets):** Sincronización bidireccional inmediata sin refrescar el navegador.
- **Votación Interactiva Multijugador/Multi-usuario:** Permite votar desde distintos dispositivos y actualiza los gráficos al instante.
- **Monitor del Sistema Operativo:** Transmite el uso de memoria RAM del servidor Node.js en vivo utilizando módulos nativos (`os`).
- **Contador de usuarios conectados en tiempo real.**

## 🛠️ Tecnologías
- **Node.js** (Entorno de ejecución)
- **Express** (Servidor HTTP)
- **Socket.io** (WebSockets bidireccionales)
- **Chart.js** (Visualización interactiva de datos)
